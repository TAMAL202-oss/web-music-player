# Web Music Player 🎵

A responsive, interactive web music player inspired by Spotify, built with pure HTML5, CSS3, and modern Vanilla JavaScript.

## 🚀 Features

- **Master Playback Controls**: Play, pause, previous, next, and auto-play next track on finish.
- **Interactive Playlist**: Click on any track from the playlist to play it immediately.
- **Real-Time Seekbar**: Synchronized progress bar with dynamic duration tracking and drag-to-seek scrubbing.
- **Visual Feedback**: Animated audio equalizer GIF and dynamic track metadata updates upon playback.
- **Responsive & Clean UI**: Styled with modern CSS flexbox and Font Awesome 6 icons.

## 🛠️ Built With

- **HTML5**: Semantic markup & HTML5 Audio API
- **CSS3**: Responsive layouts, flexbox, Google Fonts (Ubuntu & Varela Round)
- **Vanilla JavaScript**: DOM manipulation, event delegation, and media controls
- **Font Awesome 6**: Vector icons for playback and controls

## 📂 Project Structure

```text

```

## 🏁 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/TAMAL202-oss/web-music-player.git
   ```
2. Open `index.html` in your favorite web browser (or use VS Code Live Server).
3. Click the Play button or choose any track to start listening!
